# Halo96 V2 battery telemetry v0.1.0

First release for the **NuPhy Halo96 V2 QMK/VIA ANSI**. It carries the battery percentage and active charging state over the original 2.4 GHz receiver using the keyboard's battery status.

- Asset to flash with QMK Toolbox over USB is `nuphy_halo96_v2_ansi_battery_charging.bin`.
- Use `SHA256SUMS.txt` to verify the asset before flashing.
- Tested with a Halo96 V2 and its v2.1.5 receiver. The Windows reader and the battery monitor both reported `78%, charging` over 2.4 GHz.
- Existing percentage decoders can still read the percentage. The app needs the optional charging-prefix decoder to show charging.

The firmware was built from the source at this release tag with the VIA keymap and `NUPHY_BATTERY_TELEMETRY=yes`, using ARM GCC 15.2.0. See `docs/halo96-v2-battery-telemetry.md` in the tagged source for build, test, and factory rollback instructions.
