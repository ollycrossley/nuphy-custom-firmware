# Halo96 V2 firmware v0.1.1

Reduces unintended repeated keystrokes on the **NuPhy Halo96 V2 QMK/VIA ANSI** in wired USB and wireless modes. The firmware reports each key-down immediately and waits for a 5 ms stable release to filter brief switch chatter. Battery percentage and charging telemetry are available over the original 2.4 GHz receiver.

- Verify `nuphy_halo96_v2_ansi_battery_debounce.bin` against `SHA256SUMS.txt`, then flash it to the keyboard over USB using QMK Toolbox. [Build and factory rollback instructions](https://github.com/ollycrossley/nuphy-custom-firmware/blob/v0.1.1/docs/halo96-v2-battery-telemetry.md)
- The firmware passed all 22 QMK debounce tests, filtered a simulated duplicate press, and preserved rapid taps in testing. The reported typing issue cleared on the affected keyboard after flashing this build.

Built with the VIA keymap, `NUPHY_BATTERY_TELEMETRY=yes`, and ARM GCC 15.2.0.
